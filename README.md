#Отчет по заказам

## Описание
Отчет по количеству заказов в день. В отличии от встроенного отчета по
продажам, группирует заказы по дате создания, а не по факту выполнения и оплаты.

В качестве дополнения также строится график по количеству заказов,
сгруппированных по дням недели.

Принимаются пожелания по доработке. :)
